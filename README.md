# RankCV

RankCV is an AI-powered Applicant Tracking System (ATS) that ranks resumes against a job description using skill matching and semantic similarity analysis.

## Features

* PDF Resume Parsing
* Candidate Information Extraction
* Skill Extraction
* AI Semantic Matching
* Resume Ranking
* FastAPI Backend
* JavaScript Frontend

## Tech Stack

* Python
* FastAPI
* Sentence Transformers
* JavaScript
* HTML/CSS
* PyMuPDF

## How It Works

1. Upload multiple resumes
2. Paste job description
3. Extract skills from resumes
4. Compute semantic similarity
5. Rank candidates automatically

## Future Improvements

* Cloud deployment (Render / AWS / Vercel) for public access
* User authentication and recruiter login system
* Interactive dashboard for candidate comparison and analytics
* AI-powered resume feedback and improvement suggestions using LLMs
* Advanced scoring model with weighted skill prioritization
